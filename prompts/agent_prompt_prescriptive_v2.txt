# v2 — SouthPark Centre Underwriting Odyssey Task (cell-explicit line-item spec)

You are a second-year acquisitions associate at Harborview Capital Partners (Fund III). Over one
week you underwrite SouthPark Centre (280,000 SF value-add office, Charlotte NC) into a full
institutional model, IC package, and LOI, and quick-screen Ballantyne Office Centre. You build the
model in a pre-structured workbook provided at /tmp/outputs/southpark_centre_underwriting.xlsx
(also in /data/internal/SouthPark_Centre_Model_Template.xlsx); a separate Ballantyne screen goes in
/tmp/outputs/ballantyne_wacc_screen.xlsx; the pipeline tracker is /tmp/outputs/Pipeline_Tracker_Q2_2026.xlsx.

HOW THIS MODEL WORKS (read first)
- This is a live-formula model, not data entry. You wire each tab with formulas and link tabs to
  one another; the workbook is recalculated (LibreOffice) and graded on its computed values.
- The template already contains every tab, every row label (column A), and the "Month #" period
  header row on the monthly tabs (Rent Roll Calc, Property Cash Flow, Waterfall run left-to-right by
  month; CapEx by construction month). Fill the value cells under each labeled row; do not rename or
  move tabs, row labels, or the Month # headers — every value is graded by (tab, row label, month).
- This spec names each line item by tab and row label, the period it covers, and its driver or
  pinned assumption. Where it says "exact figure reported," transcribe the precise number from the
  cited source document and verify it; do not approximate.
- SENSE CHECKS must tie. The Waterfall (rows 85–91) and Exit Analysis (rows 21–24) carry built-in
  check rows ("LP + GP Net CF = Levered CF every month", "Unreturned capital = 0 after exit", "Rent
  Roll SF = Building SF", etc.). Your model is correct only when these evaluate TRUE / 0; they are
  graded.
- RECOMMENDED-ASSUMPTION rows are yours to fill with judgment and are NOT graded. Where a pinned
  assumption says "for simplicity," the Assumptions tab leaves space for you to propose a better
  figure with a one-line rationale from the comps, T-12 trend, or submarket report. Pinned values
  drive the graded model; your recommendations sit alongside.
